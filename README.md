# Manga Manager

## Introduction 
Welcome to the github repository for my project **manga manager**! Manga manager solves a problem that many manga/manhwa readers have, keeping track of the series they are following and where they read those series. Manga manager lets users store keep track 
of the series the are reading and the sites where they are reading them all in one place. Plus, it lets users create an ongoing tierlist, helps users see which series come out on which days, and can send user's email notifications, informing them what series are updated
each day.
